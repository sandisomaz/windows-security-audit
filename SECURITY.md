# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 5.5.x   | :white_check_mark: |
| < 5.5   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within the Windows Security Audit Framework, please do **not** report it in a public GitHub issue.

Instead, please report security vulnerabilities responsibly by contacting the maintainers directly or opening a private GitHub Security Advisory.

Please include the following details:
- Type of issue (e.g., local privilege escalation, command injection, path traversal, CSRF bypass)
- Step-by-step instructions to reproduce the issue
- Affected module or script file
- Any potential mitigation or patch if available

We aim to acknowledge reports within 48 hours and provide a fix or status update within 7 days.
