   - Color-coded status messages
   - Real-time progress updates

✅ ONE-CLICK SCANNING
   - No command-line needed

✅ REAL-TIME LOGGING

   - Reports saved to Desktop automatically

   - Quick: Fast essential checks (2-3 minutes)
   - Standard: Balanced analysis (5-7 minutes)

   - Forensic: Full investigation (20+ minutes)


SCAN MODES EXPLAINED
────────────────────────────────────────────────────────────────────

⚡ QUICK SCAN (2-3 minutes)
   What it checks:
   • File system integrity
   • Critical system folders
   • Disk health
   • Deep process analysis
   • Suspicious processes
   
   Best for: Daily quick health checks

─────────────────────────────────────────────────────────────────

📋 STANDARD SCAN (5-7 minutes)
   Everything in Quick Scan PLUS:
   • WMI persistence hunting
   • Registry autoruns
   • Scheduled tasks
   • Non-Microsoft services
   
   Best for: Regular weekly audits

─────────────────────────────────────────────────────────────────

🔍 DEEP SCAN (10-15 minutes) ⭐ RECOMMENDED
   Everything in Standard Scan PLUS:
   • System hardening (UAC, SecureBoot, TPM)
   • Windows Defender full analysis
   • Firewall configuration
   • Network connection analysis
   • DNS configuration
   • HOSTS file forensics
   • Browser extension audit
   • PUP detection
   
   Best for: Thorough monthly security audits

─────────────────────────────────────────────────────────────────

🔬 FORENSIC SCAN (20+ minutes)
   ALL checks enabled PLUS:
   • Verbose logging
   • File hash calculation
   • Recent executable analysis
   • Extended network analysis
   • Complete persistence hunt
   
   Best for: Suspected compromise or incident investigation


WHAT HAPPENS DURING A SCAN?
────────────────────────────────────────────────────────────────────

1. YOU CLICK A SCAN BUTTON
   ↓
2. GUI STARTS THE SECURITY AUDIT
   ↓
3. REAL-TIME UPDATES IN LOG WINDOW
   • See each check as it happens
   • Color-coded status messages
   • Progress bar updates
   ↓
4. SCAN COMPLETES
   ↓
5. REPORTS GENERATED ON DESKTOP
   • Folder: WinSecAudit_[timestamp]
   • Files: report.html, report.json, report.csv
   ↓
6. HTML REPORT OPENS AUTOMATICALLY
   ↓
7. REVIEW YOUR RESULTS


UNDERSTANDING THE REPORTS
────────────────────────────────────────────────────────────────────

The HTML report shows:

🟢 GREEN (PASS) - Everything is secure
   Example: "Real-Time Protection: Active"

🟡 YELLOW (WARN) - Minor issues, review recommended
   Example: "Windows Update: 45 days since last patch"

🔴 RED (FAIL) - Critical security issue, fix immediately
   Example: "UAC: DISABLED"

⚪ GRAY (INFO) - Informational only
   Example: "3 browser extensions installed"


RISK SCORE EXPLAINED
────────────────────────────────────────────────────────────────────

Your system gets a risk score from 0% to 100%:

🟢 LOW RISK (0-24%)
   Your system is in good security health
   → Continue regular maintenance

🟡 MEDIUM RISK (25-49%)
   Some security concerns detected
   → Review warnings and fix issues

🔴 HIGH RISK (50-100%)
   Critical security problems found
   → Take immediate action!


TIPS FOR BEST RESULTS
────────────────────────────────────────────────────────────────────

1. ⚠️ ALWAYS RUN AS ADMINISTRATOR
   Right-click START_HERE.bat → Run as Administrator

2. 📅 RUN REGULARLY
   • Quick Scan: Daily or when feeling suspicious
   • Deep Scan: Monthly for thorough audits
   • Forensic Scan: When investigating incidents

3. 💾 SAVE YOUR REPORTS
   Keep reports for baseline comparison
   "Is this worse than last month?"

4. 🔧 FIX CRITICAL ISSUES FIRST
   Always address RED (FAIL) items immediately
   Then work on YELLOW (WARN) items

5. 🔄 RE-SCAN AFTER FIXES
   Run another scan to verify fixes worked


TROUBLESHOOTING
────────────────────────────────────────────────────────────────────

PROBLEM: GUI doesn't launch
SOLUTION: 
   1. Right-click START_HERE.bat
   2. Choose "Run as Administrator"

PROBLEM: "SecurityAudit.ps1 not found"
SOLUTION: 
   Make sure ALL files are in the same folder
   Check that SecurityAudit.ps1 exists

PROBLEM: Scan takes too long
SOLUTION: 
   • Use Quick or Standard mode for faster scans
   • Deep/Forensic modes are meant to be thorough

PROBLEM: Reports not opening
SOLUTION: 
   • Check Desktop for WinSecAudit_[timestamp] folder
   • Manually open report.html from that folder
